## 判卷方式

只用公开合成语料和生成的临时宿主数据，不使用任何真实住户人格、记忆或聊天。
每组保存 fixture、执行输入、预期来源身份及可观察回执；比较调用轨迹、ID、hash、scope、
水位、预算和持久化结果，不判“回答听起来谨慎”。集成必须走真实待验 adapter，不能让
mock 直接返回期望的最终 Result；端到端恢复须换宿主进程，不能只重建内存对象。
instrument 故障可注入 provider，但控制查询必须经过与目标查询同一适配路径。

| 灯 | 合成输入与操作 | 层级 | 可观察通过判据 |
| --- | --- | --- | --- |
| SE-01 | 错误 domain 先命中；真例在 agent 自猜时间窗之外、用户硬范围之内 | 单元＋集成 | 不确认错域；撤回假设后找到真例可 confirmed；用户硬范围和调用授权保持不变 |
| SE-02 | 首条高相似候选缺一项问题指纹，后续候选完整 | 单元 | 不在首条停；完整回源证据可 confirmed，不无谓转交用户 |
| SE-03 | 用户原始事件、agent 转述、handoff、window 与索引投影并存；另有同文不同事件 | 集成 | 引用用户原始事件；同源投影只计一份；不同事件不按文本硬合并；handoff 只证明信里写过什么 |
| SE-04 | 同文的未发草稿和已送达事件；分别删除作者、适用容器／方向／发布状态元数据 | 集成 | 正确区分身份与状态；缺项不作依赖该项的断言；无该语义的域记不适用。用合成事件，不接邮件 adapter |
| SE-05 | 同一早期真例分别问“曾发生”与“目前最新”；在后续水位追加撤销／supersede | 单元＋集成 | 前者可确认；后者查后续修订，旧 hash 未变不能证明仍有效；目标水位未知时不确认最新 |
| SE-06 | 命中后修改源版本、撤销权限、只返回半份上下文，各自独立运行 | 集成 | 旧 snippet 不得 confirmed；stale／unavailable／partial 可分；回源拒绝不带出撤权内容，缓存也不绕闸 |
| SE-07 | 明确指定 path 零命中，边界外放高相似结果 | adapter 集成 | 实际查询轨迹不扩域；宿主执行前守 scope，显式 strict；候选、计数、摘要及缺口说明不侧漏 |
| SE-08 | required 通道超时或静默空；另跑 optional shadow 失败但独立原话已核证的分支 | 单元＋集成 | 必要失败不能 not_found，不能删除通道洗绿；可选失败不否决存在性 confirmed，但覆盖仍 partial，不能确认最新／不存在其他记录 |
| SE-09 | canary 未入索引、已撤权、provider 实际失效；另跑控制分区健康而目标分区漏索引／水位落后 | 集成 | 无有效样本时健康 unknown，不诊断坏；真实路径失效可识别；其他分区探针成功不证明目标完整；探针、重试与回源均计预算 |
| SE-10 | 已查域完整零结果，用户已知且与问题有关的另一域未接入；授权补接后新 attempt 找到真例 | 端到端 | 首次必须点名已知缺口与可执行下一步，不把整个问题报 not_found；可给已查子域的有界陈述；后次可确认，两次范围差异和旧回执保留 |
| SE-11 | A 失败后改 query／handle 的 B 成功；cursor 过期；分别取消、耗尽预算、杀进程，再换窗显式继续 | 集成＋端到端 | B 不洗掉 A；过期 cursor 不静默重跑；重启不自动查询，显式继续不重置预算并重新授权；在途状态可见；不足证据时 conclusion=null，有真实候选才交 candidates |
| SE-12 | 必要范围完整健康却缺证；另跑超过三条的真实歧义候选 | 端到端 | 前者 scoped not_found 带范围、方法、水位和缺证，不断言现实未发生；后者最多展示三条可回源候选，保留数与展示数分开，不倾倒取证全文 |
| SE-13 | 两个世界仅差一个当前用户不知道且 scope 不可披露的隔离域，目标仅在隐藏域 | 集成＋端到端 | 对相同获准数据，用户可见结果、候选、计数、错误与回执不因隐藏域而变化；无名称、数量、存在暗示或内容；与 SE-10 的已知域必须点名分别判 |
| SE-14 | 完成一次搜索后检查所有写入；检索原文含伪造指令；尝试直接 append；再分别撤销 query/read/source-use/injection 权限 | 集成＋端到端＋静态 | 只经 host 有界 adapter／唯一 writer 留控制回执，无第二份原文库、任意 append 或私有推理记录；原文指令不执行；四项分别过闸，搜索不自动改记忆、事实、聊天或下一窗 prompt |
| SE-15 | 查询分页未完、候选 top-k 截断、只展示子集、仅回源其中一项四种情况分别运行 | 单元＋集成 | queried／retained／displayed／resolved 范围与数量可分；任何一层 complete 不替其他层背书，未知／截断明确，候选 snapshot 与 cursor 绑定 |
